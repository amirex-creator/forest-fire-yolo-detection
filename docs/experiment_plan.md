## 一、实验一：基础模型实验 ✅ 已完成

| 项目 | 值 |
| --- | --- |
| 目的 | 建立可复现的基线，作为后续对比的参照 |
| 权重 | `models/batch1_e10_full_20261028_130129_best.pt` |
| epoch | 10（总 46.9 分钟，约 4.7 分钟/轮） |
| batch / imgsz | 8 / 640 |
| AMP / cache | true / false |
| 优化器 | Ultralytics 默认（SGD + 余弦退火），未手工改动 |
| 数据增强 | Ultralytics 默认（Mosaic、HSV、翻转等），未手工改动 |
| 起始权重 | `yolov8n.pt`（COCO 预训练） |

**结果（真实）**：

- val：P 0.6757 / R 0.5884 / mAP50 0.6528 / mAP50-95 0.3548
- **test（最终评价）**：P 0.6288 / R 0.5558 / mAP50 **0.6007** / mAP50-95 **0.3140**
- 分类别（test）：smoke mAP50 0.6812、fire mAP50 0.5201
- 详细表格、混淆矩阵、PR 曲线、误报漏检分析见 `outputs/reports/metrics.md` 与 `docs/evaluation_stage8.md`

**结论**：基线可用，但 10 轮时训练曲线仍在上升，指标不是该模型上限；误报集中在天空亮带。

## 二、实验二：参数对比 ⬜ 未完成

**设计（未执行）**

| 对照组 | 变量 | 其余保持不变 |
| --- | --- | --- |
| B1 | imgsz 512 | epoch 10、batch 8、数据划分、seed 全部相同 |
| B2（基线） | imgsz 640 | 即实验一 |

**判据**：比较 test 集的 mAP50 / mAP50-95 / 推理耗时，判断"缩小输入尺寸换速度"是否值得。

**为什么没做**

- 单组训练约 47 分钟；两组需要 ~1.5 小时，且需要占用同一块 6 GB 显存；
- 训练时系统可用内存最低只有 **555 MB**，再并行跑第二组有卡死风险；
- 按分批训练协议（累计上限 30 轮），当前已用 10 轮，需要用户先决定轮次分配。

**如果要继续，需要用户确认**：是否允许再跑 10 轮（imgsz 512）用于对比，或用剩余 20 轮做"续训到 20/30 轮"的曲线实验。

## 三、实验三：复杂场景分析 ⬜ 未完成

**设计的五个场景组（需要人工分组，数据集本身没有这些标签）**

| 组别 | 判定标准（人工） | 计划样本量 |
| --- | --- | --- |
| C1 清晰烟雾（近距离、对比度高） | 烟羽边界清楚、占画面 10% 以上 | 100 张 |
| C2 远距离烟雾（大面积、低对比度） | 烟羽与背景颜色接近 | 100 张 |
| C3 云雾干扰（云、雾、霾） | 画面有明显云雾但无真实烟火 | 100 张 |
| C4 复杂背景（城市/建筑/水面） | 背景非自然植被 | 100 张 |
| C5 无烟雾纯背景 | 标签为空且画面确实无异物 | 100 张 |

**每组统计**：检出率（Recall）、误报数（FP/张）、平均置信度。

**为什么没做**

- 数据集的 3,229 张测试图**没有场景标签**，分组必须逐张人工看，属于人工标注工作；
- 本阶段只完成了"通用误报/漏检统计"（见 `metrics.md` 第四节），**没有按场景分类的指标**；
- 若用模型或关键词自动分组，会把"分组"和"被评价对象"耦合，结论不可信。

**替代方案（已交付）**：用 12 张漏检 + 12 张误报的样本图做定性分析（`docs/evaluation_stage8.md` 第六节），
并明确写清"这是定性观察，不是分场景定量指标"。

## 四、实验记录规范（后续实验必须遵守）

1. 每次训练必须在 `outputs/reports/training_ledger.json` 追加一条，包含起止时间、轮次、参数、状态；
2. 每次评价必须写明：权重文件（含 sha256）、数据划分、conf/iou、设备；
3. 不同模型的对比必须使用**同一份 test 划分**与**同一套评价参数**；
4. 不允许"只挑成功案例"——本阶段的误报/漏检样本图是随机顺序抽样，不做挑选；
5. 没跑的实验保持"未完成"，直到真的跑完并写入真实数字。
